# Asset credits

Everything in this folder is generated by `gen.mjs` (kept outside this repo) and served from here,
so no image depends on a third-party badge service.

- **Brand logos** in `stack/` are from [Simple Icons](https://simpleicons.org) (CC0-1.0), recoloured to
  the profile palette. The logos themselves remain trademarks of their owners and are used here only
  to name the tools.
- **UI icons** (globe, mail, LinkedIn, file, database, target, workflow, clipboard, plug) are from
  [Lucide](https://lucide.dev) (ISC licence).
- **Text** is set in [Nunito](https://fonts.google.com/specimen/Nunito) and
  [JetBrains Mono](https://www.jetbrains.com/lp/mono/) (both SIL Open Font License 1.1), converted to
  outlines so it renders the same everywhere.
